# Интеграция с Angular

`Mascot3dComponent` — отдельно подключаемый standalone-компонент Angular 21.
Он сохраняет существующего тигрёнка `hg-mascot`, не добавляет маршрутов и глобального оверлея.

Импортируйте компонент напрямую из его папки в `shared`: общий файл экспортов `hg`
намеренно его не экспортирует. Three.js и GLTFLoader загружаются динамически после
первого появления компонента в области просмотра. Импорт существующего общего
файла экспортов не загружает 3D-рендерер.

```ts
import {Component, viewChild} from '@angular/core';
import {Mascot3dComponent} from '@shared/components/hg/mascot3d/mascot3d.component';

@Component({
  selector: 'app-loopy-example',
  imports: [Mascot3dComponent],
  templateUrl: './loopy-example.component.html',
  styleUrl: './loopy-example.component.scss',
})
export class LoopyExampleComponent {
  readonly mascot = viewChild.required(Mascot3dComponent);

  celebrate(): void {
    this.mascot().play('celebrate');
    this.mascot().rotateTo(Math.PI / 6);
    this.mascot().moveTo(180, 40);
  }
}
```

```html
<div class="mascot-stage">
  <hg-mascot3d [size]="240" [allowRotation]="true" />
</div>
```

```scss
.mascot-stage {
  position: relative;
  width: 100%;
  height: 360px;
  overflow: hidden;
}
```

Родительскому контейнеру нужны `position: relative` и явно ограниченные размеры.
Маскот занимает абсолютно позиционированный квадрат, изначально в левом верхнем
углу. Если контейнер меньше запрошенного размера, квадрат уменьшается.
`moveTo(x, y)` ограничивает обе координаты так, чтобы весь квадрат оставался внутри
контейнера. При изменении размеров родителя `ResizeObserver` пересчитывает размер
и допустимое положение. Перемещение использует CSS-переход длительностью 350 мс.
Автоматическое перемещение, оверлей, подключение к страницам, облачко реплики
и навигация не предусмотрены.

## Входные параметры и методы

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `src` | `assets/zanmang-loopy/3d/zanmang_loopy.glb` | URL файла GLB. При изменении старая сцена освобождается; новая загружается, когда компонент виден. |
| `fallbackSrc` | `assets/zanmang-loopy/2d/neutral.png` | PNG на время загрузки и при ошибках запроса, разбора, инициализации WebGL или потере контекста. |
| `size` | `240` | Запрошенный размер квадрата в CSS-пикселях, ограниченный размерами родителя. |
| `allowRotation` | `false` | Включает горизонтальное перетаскивание мышью или касанием и поворот с клавиатуры. |

| Метод | Поведение |
| --- | --- |
| `play(animation)` | Принимает типизированные имена из таблицы ниже. Возвращает `false`, если сцена ещё не загружена или нужного клипа нет. Запрос до загрузки запоминается. |
| `rotateTo(radians)` | Задаёт поворот вокруг оси Y. Запрос до загрузки запоминается. Неконечные значения игнорируются. |
| `moveTo(x, y)` | Перемещает в пикселях относительно родителя, ограничивая координаты его границами. Неконечные значения игнорируются. |

| Анимация | Точное имя клипа GLB |
| --- | --- |
| `idle` | `Idle` |
| `wave` | `Wave` |
| `walk` | `Walk` |
| `point` | `Point` |
| `celebrate` | `Celebrate` |
| `sad` | `Sad` |

Изначально выбрана анимация `idle`. Доступные клипы повторяются; при разрешённом
движении переход между ними занимает 200 мс с плавным смешиванием. Если клипа нет,
текущая анимация сохраняется. Анимация модели выполняется на месте: `walk` не
перемещает компонент по родительскому контейнеру.

Когда поворот разрешён, переведите фокус на маскота и нажимайте стрелки влево/вправо
для поворота на 15 градусов или Home для сброса. Доступное имя и инструкции
используют ключи `mascot3d` системы ngx-translate. Горизонтальное перетаскивание
поддерживает захват указателя; вертикальная прокрутка касанием сохраняется.
Canvas и резервное изображение — декоративные дочерние элементы доступного контейнера.

`prefers-reduced-motion: reduce` останавливает воспроизведение анимации и отключает
плавные перемещения, в том числе при изменении настройки во время работы компонента.
Ручной поворот остаётся доступным. Выход из области просмотра приостанавливает
RAF и микшер; возвращение возобновляет их работу. При уничтожении отключаются
наблюдатели и слушатели, освобождаются рендерер, геометрия, материалы, текстуры,
растровые изображения и ресурсы скелета и микшера. Если загрузка завершается после
уничтожения компонента или замены источника, её результат освобождается и не устанавливается.

При ошибках остаётся видимым PNG. Для повторной загрузки после ошибки измените `src`
или создайте компонент заново. Фоновые повторные попытки не выполняются.
Пользовательские GLB должны быть доверенными и доступны с учётом CORS; компонент
не добавляет декодеров и средств разрешения внешних URL.

## Публикация ресурсов

`angular.json` копирует только `assets/zanmang-loopy/exports/**` в
`/assets/zanmang-loopy/**`. Файлы Blender, исходники, скрипты и документация остаются
за пределами опубликованного каталога. Для стандартных путей сохраняйте подпапки
экспорта `3d` и `2d`.

## Целевые проверки

```powershell
node --experimental-vm-modules --no-warnings node_modules/jest/bin/jest.js --runInBand src/app/shared/components/hg/mascot3d/mascot3d.component.spec.ts src/app/shared/components/hg/mascot3d/mascot3d.scene.spec.ts
node node_modules/@angular/cli/bin/ng.js build
```

Компонент намеренно не подключён к рабочим страницам. Сборка приложения не проверяет
шаблон неиспользуемого компонента: при его изменении также нужна целевая проверка
компилятором Angular или сборка тестового контейнера, который его импортирует.
Тесты подменяют WebGL и загрузчик. Фактический рендеринг на GPU, размещение модели
в кадре, жесты указателя и вёрстку на компьютере и телефоне необходимо проверять
в браузере с экспортированным GLB.
