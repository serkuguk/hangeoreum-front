# Источники и ограничения

Единственный визуальный источник: файл пользователя
`docs/Hoja de giro de criatura rosa.png`, скопированный без изменений в
`references/turnaround-user.png`.

На листе подписаны FRONT, FRONT 3/4, SIDE, BACK 3/4, BACK. Подписей об авторстве,
лицензии и официальном происхождении нет. Сайты и дополнительные изображения
для внешности не использовались. Предоставление файла не трактуется как
подтверждение разрешения правообладателя на публикацию.

Подтверждены рисунком: розовая кожа, форма головы, хохолок, уши, глаза, нос,
зубы, белое брюшко, бордовые ступни и пальцы, отсутствие видимого хвоста.
Реконструированы: глубина между ракурсами, невидимые поверхности, места
сгибов, движения, выражения и освещение. Точное совпадение со всеми пикселями
2D-листа невозможно гарантировать при единой объёмной модели.

Для публичного или коммерческого использования Zanmang Loopy нужно отдельное
разрешение/лицензия. Этот процесс создаёт локальный прототип; ничего не опубликовано.
