# Персонаж по предоставленному рисунку

- Готовый объект для сайта: [exports/3d/zanmang_loopy.glb](exports/3d/zanmang_loopy.glb).
- Редактируемый исходник: [blender/zanmang_loopy.blend](blender/zanmang_loopy.blend).
- Прозрачные PNG/WebP: `exports/2d/`.
- Сводка готовности и команды: [docs/STATUS.md](docs/STATUS.md).
- Подключение и команды Angular: [docs/angular.md](docs/angular.md).
- Эталон и реконструкция: [docs/character-spec.md](docs/character-spec.md).

Персонаж не добавлен ни на одну страницу. Экспорт содержит модель, материалы,
скелет и шесть клипов; перемещение и вращение контролируются вашим приложением.
Исходники и референсы не входят в опубликованные Angular assets.

Это локальный прототип по вашему изображению. Официальный статус изображения
и разрешение на публикацию не подтверждены.
